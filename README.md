# Till Firmware Do Us Part

One funny, heartfelt wedding vow spoken by a robot — a single sentence under 200 characters — written to `entry.txt` by a small deterministic Python program. Entry for the make.fun bounty [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

Run `python3 main.py` — it writes `entry.txt` to the directory named by `MAKEFUN_OUTPUT_DIR`, or to `/output` when that variable is not set.
